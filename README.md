# 📧 Spam Email Classifier using Machine Learning

## 📌 Project Overview
This project classifies SMS or email messages as **SPAM** or **NOT SPAM** using machine learning.  
It works similar to spam filters used in Gmail and other email platforms.

---

## ❓ Problem Statement
Spam messages waste time, spread scams, and can be harmful.  
Manually identifying spam is inefficient and error-prone.

---

## ✅ Solution
A machine learning model that automatically detects spam messages based on the text content.

---

## 🧠 How It Works (Simple Explanation)
1. Load a dataset of spam and non-spam messages  
2. Convert text messages into numbers  
3. Train a machine learning model  
4. Predict whether a new message is spam or not  

---

## 🛠️ Tech Stack
- Python  
- Pandas  
- Scikit-learn  
- Naive Bayes  
- CountVectorizer  

---

## 📊 Model Details
- **Algorithm:** Multinomial Naive Bayes  
- **Input:** Message text  
- **Output:** Spam / Not Spam  

---

## 📈 Results
- **Model Accuracy:** ~97–98%  
- Very effective at detecting spam messages
